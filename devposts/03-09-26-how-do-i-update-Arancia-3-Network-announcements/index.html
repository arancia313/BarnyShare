How do i update Arancia 3 Network announcements

Here, i'm admitting it. I now have Arancia 3 Network servers, and some of you already know that. I just wanted to tell you how can i have complete access and complete control over my servers. but, you all are probably asking to me..

How can you update those announcements so easily?

I have complete control over those servers, and i literally manage to update these announcements without hardcoding or updating the page. How can i do this? I just go to the A3N repo, go to the announcement files, and update the content. BarnyShare then performs a fetch of the raw file, and that exact content of the file appears in BarnyShare's Home. Pretty smart thing, right?

And.. You know what?

I actually do the same with the BarnyShare Platform Announcements. The BarnyShare Announcements Are on the Arancia 3 Network Servers. So i edit the content, save it, commit it, and BarnyShare fetches and displays it. I do this way with both of those components. If i want to implement another component, i just go to the A3N repo, add another component, add the content, go to the platform, add a fetch mechanism, and that platform fetches that content and displays it. It's crazy how two single lines of javascript code can literally display content from something else, from just a txt file. This is really crazy.
