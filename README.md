# BarnyShare
Next generation BarnyWarp successor that is way more lightweight!
Simple to navigate, and it's packed with a sturdy version, a homepage,
an editor (written in pure scratch code), some facts, and some custom blocks!
## Sturdy
BarnyShare Sturdy was made in classic BarnyWarp, but it was ported to BarnyShare Thanks to the great import.
I's made for enjoying the classic version of BarnyWarp, without colors. It's like Classic on the projects
i have done (for some reason, it reminds me of the classic scratch 1.4 or older..).
